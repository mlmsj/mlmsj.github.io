- 在不改变现有资料分类体系的前提下，为现有夸克公开资料补充百度网盘作为第二资料入口。

## 排除范围

- 百度网盘 AI 资料已在现有清单中接入，本批不重复接入。
- 出版社散落 PDF、没有现有 Resource ID 精确对应关系的大学教材子目录、驾照合并目录及其它无法一一对应的资料暂不接入。
- 目录名称相近但无法证明是同一资料入口的内容不做猜测映射。

## 授权与校验

- 本批接入按站长在本次任务中的明确授权执行。
- 构建时仍经过现有资源元数据授权门和 Delivery 分享链接授权门；未通过授权的额外渠道不会写入公开产物。
- 公开产物不包含内部浏览记录、文件 ID、Cookie、令牌或原始请求信息。
